# Social Media Microservices

A hands-on .NET microservices project demonstrating CQRS, Event Sourcing, and event-driven communication using Apache Kafka.

## Architecture

![Architecture](docs/architecture.png)

## Technologies

- C# and .NET
- CQRS and Event Sourcing
- Apache Kafka
- MongoDB
- Microsoft SQL Server
- Entity Framework Core
- Docker
- Domain-Driven Design

## Features

- Command and query separation
- Command and query dispatchers
- Aggregate and domain event handling
- Event store using MongoDB
- Read database using SQL Server
- Event publishing and consumption with Kafka
- Event versioning and optimistic concurrency
- Event replay and read model reconstruction
